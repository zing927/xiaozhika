# 小知卡 · 第一阶段 MVP

面向小学一年级家长的语文、数学知识掌握工具。家长展示卡片，孩子先回答，家长翻卡核对，再选择「还不会 / 提示后会 / 独立会」，自动进入下一张。不计时、不排名。

**当前 60 张为原创演示题卡，不是官方完整教材，不代表任何教材版本的完整课程或教学评价。** 请结合孩子的学情及学校教学使用。

## 启动

要求 Node.js 24、npm。无需 API 密钥、数据库或环境变量。

```bash
npm ci
npm run dev
# 打开 http://localhost:3000
```

生产运行：`npm run build && npm start`。

## 功能与结构

- `/` 首页：今日练习、可练卡片、知识点概览。
- `/train` 抽卡训练：翻卡才可评分；评分后自动下一张；暂停、刷新恢复、逐次撤销；完成后仍可撤销。
- `/map` 知识地图：逐知识点展示四项掌握证据。
- `/report` 报告：总练习次数、练习自然日、独立正确次数和最近 20 次记录。
- `/settings` 设置：科目、每次 5/10/20 张、JSON 导出、清除数据（需确认）。已有训练不因设置变更而改变。
- `lib/cards.ts`：题库和知识点；`lib/learning.ts`：纯函数、复习队列、状态校验、评分和撤销；`components/app.tsx`：客户端陪练界面。
- Next.js App Router、TypeScript、Tailwind CSS v4（使用 Tailwind 的 CSS 构建入口和自定义主题样式）；无外部字体或图片依赖。桌面侧栏和移动端底部导航。

## 掌握标准

按知识点聚合所有相关题卡的评分，必须**同时**满足：

1. 至少 4 个不同自然日独立正确；自然日以评分时设备本地日期记录，不按 UTC 截断。
2. 最近 4 次练习均为独立正确，含该知识点所有题卡的练习；提示不算独立正确。
3. 至少 2 张不同题卡独立正确。
4. 首次与最后一次独立正确的自然日跨度至少 14 天。

状态：未开始 → 积累中 / 需巩固 → 已掌握。一次答对或同一天刷题不能直接掌握。掌握后出现不会或提示后会，将回到需巩固。撤销删除对应评分，复习时间和掌握状态从剩余记录重新计算，不留下虚假成功。

## 间隔复习 v1

按题卡安排到期时间：

| 评分     | 下次复习                                       |
| -------- | ---------------------------------------------- |
| 还不会   | 10 分钟后，独立正确连续次数归零                |
| 提示后会 | 24 小时后，连续次数归零                        |
| 独立会   | 连续独立正确第 1/2/3/4/5+ 次：1/3/7/14/30 天后 |

队列优先到期复习（最早到期先），再补充未练过的新卡，按科目筛选，每次最多设置的张数。未到期卡不会提前加入新队列，已有训练的队列不变化；不会的卡也不会立即循环出现造成挫败。没有到期卡会提示稍后再来。首页当前可练数展示上限 20 张。间隔使用实际经过时间，掌握天数使用当地自然日，两者各自独立。此算法是 MVP 的透明规则，不是经过教育效果验证的自适应模型。

## 题库检查与范围

共 6 个知识点，每点 10 张：10 以内加法、10 以内减法、数的大小、基础拼音、常用字认读、反义词；语数各 30 张。

- 算术逐项自动检查答案、非负结果及 10 以内范围；大小比较包含 0、相等情形。
- 拼音逐条核对四声、b/p/m/f 和 mā/bà；声母提示强调轻短读音，避免当成整个音节。
- 常用字检查无多音歧义的 10 个字与标调读音：山、水、日、月、人、口、手、田、火、木。
- 反义词采用常见、成对语境：大/小、多/少、上/下、左/右、前/后、高/矮、长/短、开/关、来/去、白/黑；由家长结合题目语境核对。
- `tests/learning.test.ts` 保存中文字音、拼音及反义词答案核对表，并检查 ID 唯一性和知识点数量。

这里的检查是演示内容的编辑核对和自动校验，未宣称官方审定。正式发布教学题库前，仍需教师审校、教材版本映射和更多题型覆盖。

## 数据和限制

- localStorage 键 `xiaozhika:v1`，带版本和运行时结构检查；保存记录、当前题目位置、翻面、暂停状态、可撤销评分 ID 和设置。
- 评分先写入存储，成功后更新界面；写入失败不推进训练。损坏记录读取失败时保留原文、提示导出原始记录后重置。
- 记录只在当前浏览器、当前站点保存。清理浏览器或切换设备不会自动恢复。导出 JSON 用于留档；本阶段无导入界面、账号、云同步、多孩子管理。
- 建议单个标签页使用；本阶段不支持多标签并发合并。依赖设备时钟，改变日期可能影响调度与统计；家长评分不是考试测评。
- 第一次打开仍需启动服务与网络加载页面；未实现离线 PWA、语音识别、计时和奖励系统。

```bash
npm test                 # 9 项题库、算法、撤销、持久化单元测试
npm run build            # 生产构建，包含 TypeScript 检查
npx playwright install chromium
npm run test:e2e         # 桌面 1440×1000、移动端 390×844
# 使用本机 Chromium 可选：
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

浏览器测试覆盖翻卡前不能评分、评分自动下一张、暂停后刷新恢复、撤销并重评、完成训练后撤销、报告和地图、设置持久化、损坏存储保留、存储失败不推进，以及掌握后提示答对导致降级。CI 自动运行单元测试、生产构建和浏览器测试。

## 手工验收

1. 新浏览器打开首页，确认统计为 0，能看到演示题库说明；在设置选数学和 5 张。
2. 进入抽卡训练并开始，确认题目面无评分按钮。让孩子回答，翻卡核对，选择任一评分，自动进入第 2 张。
3. 暂停并刷新，恢复后仍是同一张。撤销上次评分，应回到上一张答案面，可重新评分。
4. 完成 5 张，确认完成页、报告统计和最近记录；完成页撤销仍有效。刷新后记录不丢失。
5. 打开知识地图，确认一次答对只显示积累中，四项掌握证据可见。14 天、多自然日、多题卡边界由自动测试验证，无需改系统时钟等待。
6. 在手机 390px 宽度检查底部导航、卡片和三种评分均可操作，页面无横向滚动。
7. 设置中导出 JSON，核对评分和训练记录；清除时取消一次应保留数据，确认后首页与报告归零。
